# Как пересобрать ролик «Стратег — слепой выбор»

[Посмотреть MP4](strateg.mp4) · [Послушать диктора](narration.mp3) · [Разбор двух референсов](editing-guide.md)

В папке лежат исходная русская дорожка диктора и времена её 35 слов. Они позволяют повторить монтаж даже без синтезатора речи. Титры и графика привязаны к этой дорожке. В ролике четыре сцены, 627 кадров, 1080 × 1920 и 30 кадров/с. Концепт экрана семейного тарифа нарисован для объяснения идеи.

## Повтор готового монтажа

Понадобятся Python 3.12, FFmpeg с libx264 и AAC, а также семейство шрифтов DejaVu. Используются файлы DejaVuSans.ttf, DejaVuSans-Bold.ttf, DejaVuSansMono.ttf и DejaVuSansCondensed-Bold.ttf. В Linux обычно подходит системная папка DejaVu. Для другой установки задайте STRATEG_FONTS с путём к каталогу TTF. [Шрифты DejaVu](https://dejavu-fonts.github.io/)

Из этой папки выполните команды. Файл voice.wav содержит речь до понижения, timing.json — границы фраз и слов в секундах.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install 'numpy>=2,<3' Pillow==13.0.0 praat-parselmouth==0.4.7
mkdir -p build
cp voice.wav timing.json build/
.venv/bin/python mix.py build
.venv/bin/python render.py build "Стратег — слепой выбор.mp4"
```

## Новый текст и голос

Поменяйте русские фразы в SCENES файла voice.py. Скачайте два файла ru_RU-denis-medium.onnx и ru_RU-denis-medium.onnx.json из одной папки модели и положите рядом. Если меняются ключевые слова сцен, замените их в render.py и mix.py. Повторный синтез может незначительно изменить интонацию и хронометраж. [Модель Denis и карточка корпуса](https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/denis/medium)

```sh
.venv/bin/python -m pip install 'piper-tts[alignment]==1.8.0'
.venv/bin/python voice.py models/ru_RU-denis-medium.onnx build
.venv/bin/python mix.py build
.venv/bin/python render.py build "Новая версия.mp4"
```

Движок Piper работает локально. Веса не входят в этот комплект. Использован стандартный голос Denis. В карточке голосовой модели набор данных обозначен CC0. SHA-256 использованных весов — 879bc365cb14d1380e3f5ed6044162ccf54c99f6161871569b7f830aec3ce841. Код не использует запись из Instagram или YouTube. Все звуковые акценты синтезируются в mix.py. [Карточка модели](https://huggingface.co/rhasspy/piper-voices/blob/main/ru/ru_RU/denis/medium/MODEL_CARD)

## Как устроен звук и движение

Piper отдаёт длительность каждой фонемы из того же прохода, который создал звук. Скрипт объединяет их в слова по межсловным границам, учитывает обрезанные тихие края и паузы между фразами. В готовом монтаже сумма появляется на слове «шести» в 1,91 с. На «девяноста» в 5,93 с начинают расти девять столбцов. Сигналы выбора загораются в 14,90 и 15,44 с. Камера приближается к результату в 16,82 с, а третья карточка раскрывается в 18,82 с. Светлая или тёмная плашка перемещается под текущим словом.

Praat Change speaker использует множитель частоты тона 0,80, формант 0,97 и диапазона интонации 0,94. Длительность сохранена. Медиана основного тона на озвученных фрагментах в Praat составила около 140 Гц до обработки и 113 Гц после неё. В FFmpeg применены фильтр высоких частот со срезом 64 Гц, коррекции −1,8 дБ на 210 Гц и +1,5 дБ на 2,9 кГц, затем компрессия 2,6:1. Фильтр loudnorm доводит общий микс до рабочей громкости в два прохода. После кодирования в AAC измерены −15,27 LUFS-I и −1,49 dBTP. У этих величин нет обязательного значения для любого голоса или сервиса.
