# План проверки

- **Ожидаемое изменение:** метрика, направление, величина, обоснование.
- **Сравнение:** A/B-тест, если возможен; иначе — сопоставимая группа, до/после с поправкой на сезон. Объясни, почему сравнение честное.
- **Срок:** не меньше одного полного цикла (например, до первого и второго списания); учитывай размер выборки — для малого эффекта нужно много пользователей.
- **Guardrails:** что не должно ухудшиться (выручка на пользователя, жалобы, отток других сегментов, NPS) и порог остановки.
- **Правило решения** — заранее: масштабируем / откатываем / продлеваем. Без правила результат подгоняют под ожидания.
