# «Стратег» — от брифа до пересмотра решения

Руководитель цифрового продукта выбирает, стоит ли проверять предупреждение для семей, у которых заканчивается интернет. Ролик длится 3:58, формат кадра 1920 × 1080. Его можно посмотреть без аккаунта.
