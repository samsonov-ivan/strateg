# Надёжность источника (шкала Адмиралтейства, A–F)

| Код | Значение | Примеры |
|---|---|---|
| A | Полностью надёжен | Отчётность компании, официальная статистика, первоисточник данных |
| B | Обычно надёжен | Отраслевые исследования с методологией, крупные аналитические агентства |
| C | Довольно надёжен | Качественные деловые СМИ, известные эксперты со ссылками |
| D | Обычно ненадёжен | Пресс-релизы без данных, блоги, обзоры без методики |
| E | Ненадёжен | Анонимные тексты, SEO-статьи, явная заинтересованность |
| F | Нельзя оценить | Недостаточно сведений об источнике |

Факт из D–E подтверждай вторым независимым источником или понижай до hypothesis.
