# Решение (S4)

Методика: `knowledge/methods/decisions.md`.

1. Уточни у РП (одним сообщением, с предложенными значениями по умолчанию): ответственного, 1–3 метрики с базой, целью и датой, условия пересмотра.
2. Запиши:
   `strateg decision add --option O-… --rationale "…" --owner "…" --by "РП" --based-on C-…,C-… --metric "имя|база|цель|YYYY-MM-DD" --trigger "date:YYYY-MM-DD" --trigger "claim:C-…" --trigger "metric:<условие>"`
   Триггер `claim:` ставь на 1–2 самых шатких основания.
3. Обязательства из плана проверки и стратегии: `strateg commitment add --decision D-… --what "…" --owner "…" --due YYYY-MM-DD`.
4. `strateg validate`, `strateg cost` — покажи РП итог: решение, метрики, триггеры, обязательства, полная стоимость проекта (деньги + время ожидания решений).
5. `strateg project stage S5` — дальше навык `obnovit` по запросу или по сроку.
