# Анализ конкурирующих гипотез (ACH) — для вопросов «почему»

1. Выпиши 3–6 взаимоисключающих объяснений (включая скучные: сезонность, изменение методики подсчёта, ошибка данных).
2. Выпиши свидетельства (факты [C-xxx]).
3. Матрица: строки — свидетельства, столбцы — гипотезы; в ячейке: согласуется (+), противоречит (−), нейтрально (0).
4. Решает не число «+», а число «−»: побеждает гипотеза с наименьшим числом серьёзных противоречий.
5. Отметь свидетельства, которые различают гипотезы (диагностичные) — их проверяй тщательнее.
6. Итог в situation.md: ведущая гипотеза, уровень уверенности, что её опровергло бы, какие гипотезы отвергнуты и почему.
