# Стратег

ИИ-агент для руководителя цифрового продукта. По брифу он готовит записку с выбором, альтернативами, расчётом и планом проверки. При новой вводной показывает, какие выводы, разделы и поручения нужно пересмотреть.

[Пример стратегии в PDF](examples/family-strategy/strategy.pdf) · [Помесячная модель](examples/family-strategy/model.py) · [Архитектурные решения](docs/DECISIONS.md)

## Запуск

Нужны Python 3.11+ и среда с моделью, например Codex или Claude Code. Расчёты и проверки CLI работают локально. Команды для macOS и Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m strateg --help
```

Откройте корень репозитория в среде с моделью. Приложите бриф и попросите: «Создай новый проект и подготовь единую стратегию для руководителя. Покажи ближайший расход, альтернативу, как проверить гипотезу и когда пересмотреть решение». Для знакомства в [examples/demo-retention](examples/demo-retention/REQUEST.md) есть учебный запрос и синтетические данные.

Агент сохраняет ответ в `projects/<имя>/out/strategy.md`. Расходы и переходы между этапами утверждает руководитель. Для пересмотра откройте тот же проект в новом чате и сообщите новую вводную. Замените PROJECT_SLUG ниже на имя, выбранное для проекта.

```sh
.venv/bin/python -m strateg strategy check --project PROJECT_SLUG
.venv/bin/python -m strateg verify quotes --project PROJECT_SLUG
.venv/bin/python -m strateg validate --project PROJECT_SLUG
.venv/bin/python -m pytest
```

## Демонстрация

[Посмотреть короткий вертикальный ролик](examples/motion/strateg.mp4) · [Разбор голоса и анимации](examples/motion/editing-guide.md) · [Исходники и настройки рендера](examples/motion/)

В [готовом примере](examples/family-strategy/strategy.md) рассматривается предупреждение семье о возможном отключении интернета. Внутри есть допущения, помесячная модель и условия смены решения. Ссылки на источники по ID относятся к первоначальному учебному прогону. Финансовый пример можно пересчитать командой `python3 examples/family-strategy/model.py`.

В слепом сравнении на одном брифе двое из трёх ИИ-рецензентов предпочли эту записку свежему ответу обычного чата. Медианы — 10/10 и 9/10. Сильный исторический ответ обычного чата также получил 10/10.

## Как устроен агент

- [AGENTS.md](AGENTS.md) и [CLAUDE.md](CLAUDE.md) задают ход работы и правила согласования.
- [Метод подготовки записки](knowledge/methods/decision_memo.md) определяет, что руководитель должен понять из одного документа.
- [Команды CLI](strateg/cmd/) ведут источники, утверждения и решения. Арифметика проверяется в размеченных блоках `calc`. Цифры в свободном тексте требуют отдельной сверки.
- [Схемы](schemas/) и [контрактные тесты](tests/contract/) описывают сохраняемые данные и проверяемые сценарии.
