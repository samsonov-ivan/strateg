# Решение и сопровождение

- Решение принимает РП. Агент записывает: `python -m strateg decision add --option O-… --rationale … --owner … --by РП --metric "имя|база|цель|дата" --trigger "date:…" --trigger "claim:C-…"`.
- Триггеры пересмотра: дата, порог метрики, отзыв ключевого основания (claim).
- Обязательства — с ответственным и сроком: `commitment add`.
- Сопровождение: `python -m strateg review` — просрочки, сработавшие триггеры, устаревшие основания, «что решать сейчас».
- Новые данные: добавить источник/утверждение → `python -m strateg impact --changed <ID> --apply` → обновить затронутые разделы, вернуться на самый ранний затронутый этап.
