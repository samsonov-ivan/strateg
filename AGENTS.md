# Стратег — инструкции для Cursor, opencode, Codex и других сред

Полные постоянные инструкции агента — в `CLAUDE.md`: прочитай его первым и следуй ему. Здесь — только отличия для сред без Claude Code.

## Что отличается

| Возможность | Claude Code | Другие среды |
|---|---|---|
| Хуки (статус при старте, журнал, защита правил, проверка в конце хода) | срабатывают сами | **выполняй вручную**, см. ниже |
| Навыки `.claude/skills/*/SKILL.md` | вызываются по имени | открой нужный файл и следуй ему как инструкции |
| Субагенты `.claude/agents/*.md` | отдельный контекст | выполни инструкцию субагента сам, отдельным шагом; для `red-team` и `respondent` не опирайся на свои прежние выводы |
| Учёт стоимости | `strateg cost` по транскриптам | транскрипты недоступны: на каждых воротах записывай расход из интерфейса среды в `projects/<slug>/out/manual_cost.md` (дата, этап, токены или $) |

Запрос итоговой стратегии с брифом обрабатывается и в первом сообщении. Открой `.claude/skills/strategiya/SKILL.md`, создай единый документ и выполни его проверку. Если среда позволяет, передай чистому проверяющему только исходные данные и записку для проверки расчёта. Когда доступен лишь один сеанс, сделай отдельный расчёт из первичных входов и честно укажи способ проверки.

## Обязательные ручные шаги

1. **В начале сессии:** `.venv/bin/python -m strateg project status` — где остановились и следующий шаг.
2. **Не редактируй** `CLAUDE.md`, `AGENTS.md`, `.claude/`, `knowledge/`, `config/`, `schemas/`, код `strateg/` и `tests/` (даже если проверка кажется ошибочной — скажи РП), а также файлы `projects/*/state/*.jsonl`, `project.json` напрямую — только через CLI.
3. **Перед концом хода и перед воротами:** `.venv/bin/python -m strateg validate` — исправь ошибки или явно скажи РП, что осталось.
4. **Перед коммитом:** `.venv/bin/python -m strateg guard secrets --staged`.

## Перенос проекта между средами

Всё состояние — в `projects/<slug>/` (файлы JSON, JSONL, Markdown). Чтобы продолжить в другой среде: открой ту же папку, выполни шаг 1 и продолжай с указанного этапа. История решений, источники и утверждения сохраняются.
