# План исследования от решения

1. Начни с решения, а не с темы: «РП выберет между A, B, C до <даты>».
2. Для каждого кандидата в вопросы спроси: **если ответ будет X, а не Y, изменится ли выбор?** Нет — вопрос не исследуем (запиши в «не исследуем, потому что…»).
3. Ценность ответа = насколько он может поменять выбор × цена ошибки. Высокая ценность и дешёвый ответ — первым.
4. Для каждого вопроса — минимум два независимых источника разных типов (статистика/отчётность + отзывы/интерфейс + данные РП).
5. Бюджет: по умолчанию ≤3 вопроса первой волны, ≤12 источников на вопрос. Если за бюджет ответа нет — это пробел (unknown), а не повод искать бесконечно.
6. План показывается РП коротко (≤10 строк) и не блокирует работу, если РП молчит.
