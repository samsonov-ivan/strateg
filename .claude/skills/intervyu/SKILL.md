# Интервью и модельные респонденты

Методика и ограничения: `knowledge/methods/interviews.md`, приватность — `knowledge/policies/privacy.md`.

## Гайд
`projects/<slug>/docs/interview_guide.md`: цель, 2–3 сегмента, 8–12 вопросов о прошлом поведении (Mom Test), чего не спрашивать, критерий «что узнали достаточно».

## Реальные расшифровки
1. Убедись, что есть согласие. Обезличь: `strateg guard redact <файл> --names "Имя Фамилия,…"`.
2. Добавь обезличенную версию: `strateg source add --file <файл>.redacted.md --kind interview`.
3. Коды → темы; каждая тема — утверждение с цитатой (`--type fact` — «респондент сказал…», выводы о причинах — `hypothesis`). Укажи, сколько респондентов из скольких.

## Модельные респонденты (синтетика)
1. Составь 3–5 ролей из брифа (сегмент, ситуация, отношение), включая скептика и «не-пользователя». Не сообщай роли наши гипотезы.
2. Для каждой роли запусти субагента `respondent`: передай роль и вопросы гайда.
3. Сохрани ответ файлом `projects/<slug>/materials/inbox/synthetic_<роль>.md` и добавь: `strateg source add --file … --kind synthetic --title "SYNTHETIC: <роль>"`.
4. Наблюдения — `claim add --type synthetic --source S-…`. Идеи для проверки — `--type hypothesis --depends C-…`.
5. В документах каждая строка с синтетикой помечается **SYNTHETIC**. В выводах прямо пиши: «синтетика не доказывает спрос и распространённость, это гипотезы для проверки».
