# Коммуникационная стратегия

- **Ситуация аудитории:** где человек находится в момент контакта и что решает.
- **Барьер:** одно главное препятствие понимания или выбора (не знает / не верит / не видит разницы / боится потерять / дорого / сложно). Основание [C-xxx].
- **Ключевое сообщение** отвечает на барьер, а не перечисляет функции. 1 фраза + 2–3 довода.
- **Подтверждения:** каждое обещание ↔ свойство продукта ↔ факт. Обещание без свойства — ложь; без факта — недоказанно. Таблица обязательна (валидатор V09).
- **Каналы по ролям:** узнать → понять → решиться → остаться. Для каждого канала — какую роль играет и какую метрику двигает.
- Согласованность с продуктовой стратегией: аудитория та же, обещания не опережают дорожную карту.
